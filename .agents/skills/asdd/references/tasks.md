# Fase 4: Tasks

Objetivo: dividir el plan en bloques pequeños, ordenados y verificables.

## Formato de tareas
- Agrega las tareas al plan (`02-DOCS/wiki/sdd/plans/<slug>.md`) o a `02-DOCS/wiki/sdd/progress/<slug>.md` con IDs `T001`, `T002`, etc.
- Cada tarea debe indicar:
  1. **Alcance acotado** (1 responsabilidad clara).
  2. **Archivos objetivo**.
  3. **Prueba o verificación** que demuestra que quedó completa.
- Respeta dependencias (ej. esquema/migración → lógica/validación → rutas → UI).
